## Projects

### [NYC Open Data Payroll Forecasting]([https://github.com/nisargakadam](https://github.com/nisargakadam/nycopendata-payroll-dashboard))
> *Random Forest · DuckDB · Anomaly Detection · Pay Equity*

Engineered a data pipeline over **6.5M rows** from the NYC OpenData API using DuckDB. Derived features like tenure, OT ratio, and total compensation across city agencies. Trained a Random Forest Regression model (R² = 0.72) to predict salaries and flag pay equity outliers. Applied Isolation Forest to detect overtime anomalies across 135,000 workers.

---

### [MLB Batting Lineup Optimizer](https://github.com/nisargakadam/baseball-simulation-project)
> *Monte Carlo Simulation · Genetic Algorithm · Python · Sports Analytics*

Simulated **1.5M Yankees games** using a Discrete-Time Markov Chain framework. Derived appearance transition probabilities from SportsRadar and Baseball-Reference data. Implemented a genetic algorithm (50-lineup population, 30 generations) to optimize batting order, validated with CLT-based 95% confidence intervals.

---

### [Fake Review Detection & Amazon Recommendation Engine](https://github.com/nisargakadam/Influence-of-Fake-Reviews-on-Quality-Amazon-Product-Recommendation)
> *NLP · SVC · Logistic Regression · Decision Trees · F1-Score*

Built NLP/ML classifiers to detect fake reviews and improve product recommendation quality on Amazon data. Evaluated models using F1-score to account for class imbalance.

### [Dine & Dice — NYC Restaurant Discovery](https://spin-nyc.vercel.app)

A restaurant roulette app for NYC built with Next.js and a Flask backend. Integrates the Google Maps API to help users discover local spots by neighborhood, cuisine, and vibe. Live at [spin-nyc.vercel.app](https://spin-nyc.vercel.app).
